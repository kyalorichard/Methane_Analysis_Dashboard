# v10 release notes — visual and usability refinement

This release refines the v9 Streamlit interface without changing the underlying scientific analysis workflows.

### Main changes
- Reworked the shared visual system: typography, colours, spacing, panels, metrics, buttons, inputs, charts, tables, alerts and responsive behaviour.
- Added a clearer sidebar identity, data import section and active dataset status.
- Rebuilt the empty-state landing page around a guided three-step start and recommended scientific analysis sequence.
- Standardised page headers through the existing shared UI helper.
- Added UI/UX documentation.

### Validation
- Python compilation passed.
- Automated test suite: 25 passed, 1 benign warning from a formula-builder test.
- No new dependencies.
- Browser-level visual QA remains recommended before deployment.
