# Release 6.6.0 — Conventional statistics versus machine learning

Replaces the narrow OLS-versus-single-estimator benchmark with a matched grouped-CV comparison framework. Includes OLS, GEE, random-intercept mixed-effects models, spline regression, median quantile regression, allometric power-law regression and selected ML models. Adds paired group-bootstrap RMSE difference intervals, out-of-fold predictions and downloadable publication-oriented result tables.

See `docs/RELEASE_6_6_STATISTICAL_ML_COMPARISON.md` for methods, interpretation and limitations.
